## Player stats
```dataview

TABLE
  player_link AS Player,
  games,
  goals,
  disposals,
  marks,
  tackles
FROM ""
WHERE team = this.team
  AND Year = this.Year
  AND player
SORT goals DESC

```


## Team Totals
``` dataview

TABLE
  sum(goals) AS Goals,
  sum(disposals) AS Disposals,
  sum(marks) AS Marks,
  sum(tackles) AS Tackles
FROM ""
WHERE team = this.team
  AND Year = this.Year
  AND player

```

## Team Averages
``` dataview

TABLE
  round(sum(goals)/sum(games), 2) AS Goals_per_Game,
  round(sum(disposals)/sum(games), 2) AS Disposals_per_Game
FROM ""
WHERE team = this.team
  AND Year = this.Year
  AND player

```

## Team History
``` dataview

TABLE
  year,
  sum(goals) AS Goals,
  sum(disposals) AS Disposals
FROM ""
WHERE team = this.team
GROUP BY Year
SORT Year DESC

```
